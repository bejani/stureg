# StuReg

سامانه‌ی وب PHP/MySQL برای جمع‌آوری رضایت‌محور اطلاعات دانش‌آموزان، ارتباط پیامکی داخلی با مدیر و علامت‌گذاری موارد نیازمند پیگیری مشاور مدرسه.

## امکانات نسخه اول

- ورود دانش‌آموز با شماره موبایل و رمز اختصاصی که مدیر ایجاد می‌کند.
- فرم اطلاعات فردی، والدین، تماس اضطراری و سلامت با ثبت زمان رضایت.
- پنل دانش‌آموز برای ویرایش اطلاعات و ارسال/دریافت پیام.
- پنل مدیر برای فهرست دانش‌آموزان، مشاهده پرونده، دیدن پیام‌ها، پاسخ‌گویی و علامت «نیازمند پیگیری/ارجاع».
- استفاده از PDO، کوئری‌های prepared، هش رمز عبور، CSRF و escape خروجی.

## راه‌اندازی محلی

1. PHP 8.1+، MySQL 5.7+/MariaDB و وب‌سرور Apache نصب کنید.
2. دیتابیس را بسازید: `mysql -u root -p < schema.sql`
3. در صورت نیاز مقادیر `includes/config.php` را تغییر دهید. برای سرور واقعی بهتر است این فایل خارج از web root نگه‌داری شود.
4. رمز هش‌شده‌ی مدیر بسازید: `php -r "echo password_hash('رمز-قوی', PASSWORD_DEFAULT), PHP_EOL;"`
5. دستور INSERT کامنت‌شده در `schema.sql` را با هش تولیدشده اجرا کنید. برای هر دانش‌آموز نیز یک رکورد در جدول `users` بسازید؛ نقش باید `student` باشد.
6. از ریشه پروژه اجرا کنید: `php -S localhost:8000` و سپس `http://localhost:8000` را باز کنید.

## انتقال به InfinityFree

فایل‌ها را در `htdocs` آپلود کنید، دیتابیس و کاربر MySQL را در کنترل‌پنل بسازید، `schema.sql` را از طریق phpMyAdmin وارد کنید و مقادیر اتصال را مطابق اطلاعات InfinityFree تنظیم کنید. مسیرهای این نسخه از ریشه دامنه شروع می‌شوند؛ اگر پروژه در یک زیرپوشه نصب شد، مسیرهای `/assets` و `/login.php` را به مسیر پایه‌ی سایت تغییر دهید.

## ملاحظات حریم خصوصی

اطلاعات سلامت و تماس اضطراری داده‌ی حساس است. قبل از استفاده واقعی، متن رضایت را با سیاست مدرسه/قوانین محل تطبیق دهید، دسترسی مدیر را محدود کنید، رمزها را قوی و HTTPS را فعال کنید، پشتیبان‌گیری امن و سیاست حذف/نگهداری داده داشته باشید. این نسخه ابزار پیام‌رسان داخلی دارد و جایگزین پروتکل رسمی ارجاع اورژانسی یا مشاوره نیست.

## ساخت حساب‌ها

این نسخه برای کاهش ریسک، ثبت‌نام عمومی ندارد. مدیر باید حساب دانش‌آموز را با رمز موقت تولید و از مسیر امن در اختیار او بگذارد؛ در نسخه بعدی می‌توان تغییر رمز اجباری، بازیابی رمز و ورود دومرحله‌ای را افزود.
